# QADR Documentation

This directory contains the VitePress documentation site for QADR.

## Development

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
# Build for production
pnpm build

# Preview production build
pnpm preview
```

## Adding Pages

1. Create a new `.md` file in the appropriate directory
2. Add it to the sidebar in `.vitepress/config.ts`
3. Write content using Markdown + VitePress features

## VitePress Features

### Code Groups

````markdown
::: code-group

```bash [npm]
npm install @qadr/cli
```

```bash [pnpm]

:::
````

## Deployment

The documentation is deployed automatically when changes are pushed to `main`.

### Vercel

```bash
vercel --prod
```

### Netlify

```bash
netlify deploy --prod --dir=.vitepress/dist
```

### GitHub Pages

```yaml
# .github/workflows/docs.yml
name: Deploy Docs

on:
  push:
    branches: [main]
    paths: [docs/**]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - run: pnpm install
      - run: pnpm --filter @qadr/docs build
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: docs/.vitepress/dist
```

## Writing Guidelines

1. **Be concise**: Get to the point quickly
2. **Use examples**: Show, don't just tell
3. **Test code**: Ensure all code examples work
4. **Link related**: Cross-reference related pages
5. **Update often**: Keep docs in sync with code
