# CLI

The QADR Command-Line Interface provides powerful dependency resolution from the terminal.

## Installation

```bash
npm install -g @qadr/cli
```

## Commands

### resolve

Resolve dependencies and generate a lockfile.

```bash
qadr resolve [options]
```

**Options:**
- `--manifest, -m <path>` - Path to package.json (default: `./package.json`)
- `--lockfile, -l <path>` - Output lockfile path (default: `./qadr.lock`)
- `--registry <url>` - Registry URL
- `--no-cache` - Disable caching
- `--force` - Force fresh resolution
- `--dry-run` - Show what would be resolved without writing

**Example:**
```bash
qadr resolve --manifest ./packages/app/package.json
```

### analyze

Analyze dependencies without resolving.

```bash
qadr analyze [options]
```

**Options:**
- `--manifest, -m <path>` - Path to package.json
- `--depth <number>` - Maximum depth to analyze (default: `Infinity`)
- `--prod` - Only production dependencies
- `--dev` - Only development dependencies
- `--json` - Output as JSON

**Example:**
```bash
qadr analyze --json > analysis.json
```

### audit

Check for security vulnerabilities.

```bash
qadr audit [options]
```

**Options:**
- `--level <severity>` - Minimum severity (critical, high, medium, low)
- `--json` - Output as JSON
- `--fix` - Attempt to fix vulnerabilities

**Example:**
```bash
qadr audit --level high --json
```

### benchmark

Compare QADR performance against npm.

```bash
qadr benchmark [options]
```

**Options:**
- `--iterations <number>` - Number of iterations (default: `5`)
- `--warmup <number>` - Warmup iterations (default: `2`)
- `--compare <manager>` - Compare against (npm, yarn, pnpm)

**Example:**
```bash
qadr benchmark --iterations 10 --compare pnpm
```

### init

Initialize QADR configuration.

```bash
qadr init [options]
```

**Options:**
- `--typescript` - Create TypeScript config
- `--json` - Create JSON config

### config

View or modify configuration.

```bash
qadr config [subcommand]
```

**Subcommands:**
- `get <key>` - Get a config value
- `set <key> <value>` - Set a config value
- `list` - List all config values

## Global Options

These options work with all commands:

```bash
--help, -h        Show help
--version, -v     Show version
--verbose         Verbose output
--quiet, -q       Suppress output
--no-color        Disable colors
--config <path>   Custom config file path
```

## Examples

### Basic Resolution

```bash
# Resolve dependencies
qadr resolve

# View analysis
qadr analyze

# Check security
qadr audit
```

### CI/CD Pipeline

```bash
# Fail on vulnerabilities
qadr resolve
qadr audit --level high || exit 1
```

### Monorepo

```bash
# Resolve all packages
qadr resolve --manifest ./package.json
qadr resolve --manifest ./packages/app/package.json
qadr resolve --manifest ./packages/lib/package.json
```

## Exit Codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | General error |
| 2 | Resolution failed |
| 3 | Vulnerabilities found (with `--fail-on`) |
| 4 | Invalid arguments |
| 5 | Config error |

## Environment Variables

The CLI respects these environment variables:

- `QADR_REGISTRY` - Default registry URL
- `QADR_CACHE_DIR` - Cache directory
- `QADR_NO_COLOR` - Disable colors
- `QADR_VERBOSE` - Enable verbose output
- `NPM_TOKEN` - Authentication token
