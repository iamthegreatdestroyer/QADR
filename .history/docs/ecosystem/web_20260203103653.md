# Web Dashboard

The QADR Web Dashboard provides a visual interface for dependency analysis and management.

## Features

- 📊 **Interactive Graphs** - Visualize your dependency tree
- 🔍 **Search & Filter** - Find packages quickly
- 🛡️ **Security Overview** - At-a-glance vulnerability status
- 📈 **Analytics** - Track dependency trends over time
- 🔄 **Real-time Updates** - Live analysis results

## Getting Started

### Local Development

```bash
# Clone the repository
git clone https://github.com/iamthegreatdestroyer/QADR.git
cd QADR

# Install dependencies
pnpm install

# Start the web dashboard
pnpm --filter @qadr/web dev
```

Open [http://localhost:3000](http://localhost:3000).

### Production Deployment

The web dashboard can be deployed to any platform supporting Next.js:

#### Vercel (Recommended)

```bash
npx vercel --prod
```

#### Docker

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY . .
RUN pnpm install && pnpm --filter @qadr/web build
EXPOSE 3000
CMD ["pnpm", "--filter", "@qadr/web", "start"]
```

## Pages

### Dashboard (`/`)

The main dashboard shows:

- Quick stats (total packages, vulnerabilities, outdated)
- Recent analyses
- Quick actions

### Analyze (`/analyze`)

Upload or paste a `package.json` to analyze:

1. Paste your `package.json` content
2. Click **Analyze**
3. View detailed breakdown

### Resolve (`/resolve`)

Run full resolution on a manifest:

1. Upload `package.json`
2. Configure options
3. Click **Resolve**
4. Download resulting lockfile

### Benchmark (`/benchmark`)

Compare QADR performance:

1. Upload `package.json`
2. Run benchmark
3. See speed comparison chart

## API Endpoints

The web dashboard exposes REST APIs:

### POST `/api/analyze`

Analyze a package manifest.

```bash
curl -X POST http://localhost:3000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"manifest": {"dependencies": {"lodash": "^4.0.0"}}}'
```

**Response:**
```json
{
  "stats": {
    "total": 1,
    "production": 1,
    "development": 0
  },
  "vulnerabilities": [],
  "outdated": []
}
```

### POST `/api/resolve`

Resolve dependencies.

```bash
curl -X POST http://localhost:3000/api/resolve \
  -H "Content-Type: application/json" \
  -d '{"manifest": {"dependencies": {"react": "^18.0.0"}}}'
```

**Response:**
```json
{
  "packages": [
    {"name": "react", "version": "18.2.0", "integrity": "..."},
    {"name": "react-dom", "version": "18.2.0", "integrity": "..."}
  ],
  "stats": {
    "total": 2,
    "time": 150
  }
}
```

### POST `/api/benchmark`

Run performance benchmark.

```bash
curl -X POST http://localhost:3000/api/benchmark \
  -H "Content-Type: application/json" \
  -d '{"manifest": {"dependencies": {"express": "^4.0.0"}}}'
```

**Response:**
```json
{
  "qadr": {
    "time": 150,
    "packages": 50
  },
  "npm": {
    "time": 1200,
    "packages": 50
  },
  "speedup": 8.0
}
```

## Configuration

Configure via environment variables:

```bash
# .env.local
QADR_REGISTRY=https://registry.npmjs.org
QADR_CACHE_ENABLED=true
QADR_CACHE_DIR=.qadr-cache
```

## Customization

### Theming

The dashboard supports light and dark themes. Toggle via the theme button in the header.

Custom colors can be set in `tailwind.config.js`:

```javascript
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: '#7c3aed',
        secondary: '#10b981',
      },
    },
  },
};
```

### Embedding

Embed the dashboard in your own application:

```html
<iframe 
  src="https://qadr.dev/embed/analyze"
  width="100%"
  height="600"
  frameborder="0"
></iframe>
```
