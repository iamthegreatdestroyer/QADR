# Configuration

QADR can be configured through multiple methods, with the following precedence (highest to lowest):

1. CLI flags
2. Environment variables
3. Configuration file (`qadr.config.ts`)
4. Default values

## Configuration File

Create a `qadr.config.ts` (or `.qadrrc.json`) in your project root:

```typescript
import { defineConfig } from '@qadr/config';

export default defineConfig({
  // Resolver settings
  resolver: {
    strategy: 'quantum-annealing',
    temperature: 1.0,
    coolingRate: 0.995,
    maxIterations: 10000,
    parallelism: 'auto',
  },

  // Registry settings
  registry: {
    url: 'https://registry.npmjs.org',
    timeout: 30000,
    retries: 3,
    token: process.env.NPM_TOKEN,
  },

  // Cache settings
  cache: {
    enabled: true,
    directory: '.qadr-cache',
    ttl: '7d',
    maxSize: '500mb',
  },

  // Security settings
  security: {
    audit: true,
    failOnVulnerability: 'high', // 'critical' | 'high' | 'medium' | 'low' | false
    allowedAdvisories: [],
    ignorePatterns: [],
  },

  // Output settings
  output: {
    format: 'auto', // 'json' | 'text' | 'auto'
    colors: true,
    verbose: false,
    quiet: false,
  },

  // Lockfile settings
  lockfile: {
    path: 'qadr.lock',
    format: 'yaml', // 'yaml' | 'json'
    includeIntegrity: true,
  },

  // Hooks
  hooks: {
    beforeResolve: async (manifest) => {
      console.log('Starting resolution...');
      return manifest;
    },
    afterResolve: async (result) => {
      console.log(`Resolved ${result.packages.length} packages`);
      return result;
    },
  },
});
```

## Supported File Formats

QADR looks for configuration in these files (in order):

1. `qadr.config.ts`
2. `qadr.config.js`
3. `qadr.config.mjs`
4. `qadr.config.cjs`
5. `.qadrrc`
6. `.qadrrc.json`
7. `.qadrrc.yaml`
8. `.qadrrc.yml`
9. `package.json` (`qadr` field)

## Environment Variables

All configuration options can be set via environment variables:

| Variable | Description | Example |
|----------|-------------|---------|
| `QADR_REGISTRY` | Registry URL | `https://registry.npmjs.org` |
| `QADR_CACHE_DIR` | Cache directory | `.qadr-cache` |
| `QADR_CACHE_ENABLED` | Enable caching | `true` |
| `QADR_SECURITY_AUDIT` | Enable audit | `true` |
| `QADR_VERBOSE` | Verbose output | `false` |
| `QADR_NO_COLOR` | Disable colors | `false` |

See [Environment Variables](/config/environment) for the complete list.

## CLI Flags

Most options can be overridden via CLI flags:

```bash
qadr resolve \
  --registry https://registry.npmjs.org \
  --cache-dir .qadr-cache \
  --no-cache \
  --audit \
  --fail-on high \
  --verbose
```

See [CLI Reference](/config/cli) for all available flags.

## Per-Ecosystem Configuration

Configure different settings per ecosystem:

```typescript
export default defineConfig({
  // Default settings
  cache: { enabled: true },

  // Ecosystem-specific overrides
  ecosystems: {
    npm: {
      registry: { url: 'https://registry.npmjs.org' },
    },
    cargo: {
      registry: { url: 'https://crates.io' },
    },
    pip: {
      registry: { url: 'https://pypi.org/simple' },
    },
  },
});
```

## Workspace Configuration

For monorepos, you can have root and package-level configs:

```
my-monorepo/
├── qadr.config.ts          # Root config (shared settings)
├── packages/
│   ├── app/
│   │   └── qadr.config.ts  # Package-specific overrides
│   └── lib/
│       └── qadr.config.ts
```

Package configs inherit from and override root config.
