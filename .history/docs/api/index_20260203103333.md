# API Reference

This section covers the programmatic API for QADR packages.

## Packages

QADR is organized as a monorepo with several packages:

| Package | Description |
|---------|-------------|
| [`@qadr/core`](/api/resolver) | Core resolution engine |
| [`@qadr/semver`](/api/semver) | Semantic version parsing and comparison |
| [`@qadr/shared`](/api/types) | Shared types and utilities |
| [`@qadr/config`](/config/) | Configuration loading |

## Quick Examples

### Basic Resolution

```typescript
import { createResolver } from '@qadr/core';

const resolver = createResolver({
  registry: 'https://registry.npmjs.org',
  cache: true,
});

const result = await resolver.resolve({
  dependencies: {
    'lodash': '^4.17.0',
    'express': '^4.18.0',
  },
});

console.log(result.packages);
// [
//   { name: 'lodash', version: '4.17.21', ... },
//   { name: 'express', version: '4.18.2', ... },
//   ...
// ]
```

### Semver Parsing

```typescript
import { parse, satisfies, compare } from '@qadr/semver';

const version = parse('1.2.3-beta.1+build.123');
// { major: 1, minor: 2, patch: 3, prerelease: ['beta', 1], build: ['build', '123'] }

satisfies('1.2.3', '^1.0.0');  // true
satisfies('2.0.0', '^1.0.0');  // false

compare('1.2.3', '1.2.4');  // -1
compare('1.2.3', '1.2.3');  // 0
compare('1.2.4', '1.2.3');  // 1
```

### Dependency Analysis

```typescript
import { createAnalyzer } from '@qadr/core';

const analyzer = createAnalyzer();

const analysis = await analyzer.analyze('./package.json');

console.log(analysis.stats);
// {
//   total: 150,
//   production: 45,
//   development: 105,
//   vulnerabilities: { critical: 0, high: 2, medium: 5, low: 3 },
// }
```

## Type System

QADR is written in TypeScript and exports comprehensive types:

```typescript
import type {
  Dependency,
  Package,
  ResolvedPackage,
  Vulnerability,
  VersionRange,
  ResolverOptions,
  AnalysisResult,
} from '@qadr/shared';
```

## Error Handling

All QADR operations throw typed errors:

```typescript
import {
  QADRError,
  ResolutionError,
  NetworkError,
  ValidationError,
} from '@qadr/shared';

try {
  await resolver.resolve(manifest);
} catch (error) {
  if (error instanceof ResolutionError) {
    console.error('Conflict:', error.conflicts);
  } else if (error instanceof NetworkError) {
    console.error('Network issue:', error.cause);
  }
}
```
