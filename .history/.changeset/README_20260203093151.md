# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos, or single-package repos to help you version and publish your code.

You can find the full documentation for it [in the changesets repository](https://github.com/changesets/changesets).

## What's a changeset?

A changeset is a piece of information about changes made in a branch or commit. It holds three key bits of information:

- What we need to release
- What version we're releasing packages at (using semantic versioning)
- A changelog entry for the released packages

## How to add a changeset

1. Run `pnpm changeset`
2. Select the packages you want to release
3. Select the semver bump type
4. Write a summary of the changes
