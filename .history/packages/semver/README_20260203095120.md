# @qadr/semver

> Semantic versioning utilities for QADR

Fast, lightweight semantic versioning library with full SemVer 2.0.0 support.

## Installation

```bash
pnpm add @qadr/semver
```

## Usage

### Parsing Versions

```typescript
import { parse, isValid, coerce } from '@qadr/semver';

// Parse a version string
const version = parse('1.2.3-alpha.1+build.123');
console.log(version);
// {
//   major: 1,
//   minor: 2,
//   patch: 3,
//   prerelease: ['alpha', '1'],
//   build: ['build', '123'],
//   raw: '1.2.3-alpha.1+build.123'
// }

// Check if valid
isValid('1.0.0'); // true
isValid('invalid'); // false

// Coerce loose formats
coerce('v1.2'); // { major: 1, minor: 2, patch: 0, ... }
coerce('1'); // { major: 1, minor: 0, patch: 0, ... }
```

### Comparing Versions

```typescript
import { compare, gt, lt, eq, sort, max, min } from '@qadr/semver';

// Compare versions
compare('1.0.0', '2.0.0'); // -1 (a < b)
compare('2.0.0', '1.0.0'); // 1 (a > b)
compare('1.0.0', '1.0.0'); // 0 (a == b)

// Comparison helpers
gt('2.0.0', '1.0.0'); // true
lt('1.0.0-alpha', '1.0.0'); // true
eq('1.0.0', '1.0.0'); // true

// Sort versions
sort(['2.0.0', '1.0.0', '1.5.0']);
// ['1.0.0', '1.5.0', '2.0.0']

sort(['2.0.0', '1.0.0', '1.5.0'], 'desc');
// ['2.0.0', '1.5.0', '1.0.0']

// Find min/max
max(['1.0.0', '2.0.0', '1.5.0']); // '2.0.0'
min(['1.0.0', '2.0.0', '1.5.0']); // '1.0.0'
```

### Version Constraints

```typescript
import { satisfies, maxSatisfying, minSatisfying, filter } from '@qadr/semver';

// Check if version satisfies constraint
satisfies('1.2.3', '^1.0.0'); // true
satisfies('2.0.0', '^1.0.0'); // false
satisfies('1.5.0', '>=1.0.0 <2.0.0'); // true
satisfies('1.0.0', '1.0.0 || 2.0.0'); // true

// Find best matching version
const versions = ['1.0.0', '1.5.0', '2.0.0', '2.5.0'];

maxSatisfying(versions, '^1.0.0'); // '1.5.0'
minSatisfying(versions, '>=2.0.0'); // '2.0.0'

// Filter versions
filter(versions, '^1.0.0'); // ['1.0.0', '1.5.0']
```

### Supported Constraint Syntax

| Syntax | Description | Example |
|--------|-------------|---------|
| `1.2.3` | Exact version | `1.2.3` |
| `=1.2.3` | Exact version | `1.2.3` |
| `>1.2.3` | Greater than | `1.2.4`, `2.0.0` |
| `>=1.2.3` | Greater or equal | `1.2.3`, `2.0.0` |
| `<1.2.3` | Less than | `1.2.2`, `1.0.0` |
| `<=1.2.3` | Less or equal | `1.2.3`, `1.0.0` |
| `^1.2.3` | Compatible with | `1.2.3` - `1.x.x` |
| `~1.2.3` | Approximately | `1.2.3` - `1.2.x` |
| `1.2.x` | Any patch | `1.2.0` - `1.2.999` |
| `1.x` | Any minor | `1.0.0` - `1.999.999` |
| `*` | Any version | All versions |
| `1.0.0 - 2.0.0` | Hyphen range | `1.0.0` to `2.0.0` |
| `>=1.0.0 <2.0.0` | AND | Both conditions |
| `^1.0.0 \|\| ^2.0.0` | OR | Either condition |

### Incrementing Versions

```typescript
import { parse, increment, format } from '@qadr/semver';

const version = parse('1.2.3')!;

format(increment(version, 'major')); // '2.0.0'
format(increment(version, 'minor')); // '1.3.0'
format(increment(version, 'patch')); // '1.2.4'
format(increment(version, 'prerelease')); // '1.2.4-alpha.0'
```

## API Reference

### Types

- `ISemVer` - Parsed semantic version object
- `IVersionConstraint` - Parsed constraint
- `ConstraintOperator` - `=`, `!=`, `>`, `>=`, `<`, `<=`, `^`, `~`, `*`
- `CompareResult` - `-1 | 0 | 1`

### Parsing Functions

- `parse(version, options?)` - Parse version string
- `isValid(version)` - Check if valid
- `coerce(version)` - Coerce loose formats
- `format(version, options?)` - Format to string
- `increment(version, type)` - Increment version

### Comparison Functions

- `compare(a, b)` - Compare versions (-1, 0, 1)
- `gt(a, b)`, `gte(a, b)`, `lt(a, b)`, `lte(a, b)`, `eq(a, b)`, `neq(a, b)`
- `sort(versions, order?)` - Sort version array
- `min(versions)`, `max(versions)` - Find extremes
- `diff(a, b)` - Find difference type

### Constraint Functions

- `parseConstraint(constraint)` - Parse constraint string
- `satisfies(version, constraint)` - Check satisfaction
- `maxSatisfying(versions, constraint)` - Find max match
- `minSatisfying(versions, constraint)` - Find min match
- `filter(versions, constraint)` - Filter matching
- `isValidConstraint(constraint)` - Validate constraint
