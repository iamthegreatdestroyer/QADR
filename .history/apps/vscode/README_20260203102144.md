# QADR VS Code Extension

> Quantum-Annealed Dependency Resolution for Visual Studio Code

The QADR VS Code extension brings intelligent dependency analysis and resolution directly into your editor. Powered by quantum-inspired optimization algorithms, it helps you manage dependencies with unprecedented efficiency.

## Features

### 🔍 Intelligent Dependency Analysis

- **Real-time vulnerability detection** - Identify security issues as you code
- **License compliance checking** - Spot problematic licenses before they cause issues
- **Update notifications** - Know when newer versions are available
- **Bundle size insights** - Understand the impact of your dependencies

### 🌳 Dependency Tree View

Visualize your entire dependency graph in the Explorer sidebar:

- View production, development, peer, and optional dependencies
- See transitive dependencies at any depth
- Quickly identify vulnerable or outdated packages

### ⚡ Quick Fixes

Resolve issues with a single click:

- Update packages to the latest version
- Apply security patches for vulnerabilities
- Navigate to npm or bundlephobia for more details

### 📊 Analysis Report

Generate comprehensive reports showing:

- Total dependencies and vulnerabilities
- Severity breakdown (critical, high, medium, low)
- Actionable recommendations

## Installation

1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "QADR"
4. Click Install

Or install via command line:

```bash
code --install-extension qadr.qadr
```

## Usage

### Commands

| Command | Description | Shortcut |
|---------|-------------|----------|
| `QADR: Resolve Dependencies` | Run quantum-annealed resolution | - |
| `QADR: Analyze Dependencies` | Analyze without resolution | - |
| `QADR: Show Report` | Open the analysis report panel | - |
| `QADR: Show Dependency Tree` | Focus the dependency tree view | - |
| `QADR: Open Settings` | Configure QADR options | - |
| `QADR: Benchmark` | Run performance benchmark | - |

### Hover Information

Hover over any dependency in `package.json` to see:

- Current and latest versions
- Vulnerability information
- License details
- Links to npm and bundlephobia

### Diagnostics

QADR adds inline diagnostics for:

- 🔴 Critical and high severity vulnerabilities
- 🟡 Medium severity vulnerabilities
- 🔵 Available updates
- ⚠️ License issues

### Tree View

The QADR Dependencies view in the Explorer sidebar shows:

- **Vulnerabilities** - Packages with known security issues
- **Updates Available** - Packages with newer versions
- **Dependencies** - Production dependencies
- **Dev Dependencies** - Development dependencies
- **Optional/Peer** - Other dependency types

## Configuration

Configure QADR in VS Code settings (`Ctrl+,`):

| Setting | Description | Default |
|---------|-------------|---------|
| `qadr.autoAnalyze` | Automatically analyze on manifest changes | `true` |
| `qadr.showInlineHints` | Show inline hints for updates | `true` |
| `qadr.securityLevel` | Minimum severity for diagnostics | `"medium"` |
| `qadr.showVulnerabilities` | Show vulnerability diagnostics | `true` |
| `qadr.showLicenseWarnings` | Show license issue warnings | `true` |
| `qadr.strategy` | Resolution strategy (quantum, greedy, backtracking) | `"quantum"` |
| `qadr.cacheEnabled` | Enable caching for faster analysis | `true` |
| `qadr.cacheTtl` | Cache time-to-live in seconds | `3600` |

## Troubleshooting

### Extension not activating

Ensure you have a supported manifest file in your workspace:
- `package.json` for npm projects

### Analysis not showing results

1. Check the QADR output channel (View → Output → QADR)
2. Ensure your manifest is valid JSON
3. Try running "QADR: Analyze Dependencies" manually

### High memory usage

Disable caching in settings:
```json
{
  "qadr.cacheEnabled": false
}
```
