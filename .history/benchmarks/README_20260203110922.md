# QADR Benchmarks

Performance benchmarks for the Quantum-Annealed Dependency Resolution system.

## Running Benchmarks

```bash
# Run all benchmarks
pnpm benchmark

# Run specific benchmark
pnpm benchmark -- --filter=qubo

# Compare with baseline
pnpm benchmark:compare
```

## Benchmark Categories

### Core Algorithms

- **QUBO Construction** - Measures time to build QUBO matrices
- **Simulated Annealing** - Single-chain annealing convergence
- **Parallel Tempering** - Multi-replica performance scaling

### Ecosystem Adapters

- **npm** - Resolution of npm package trees
- **pip** - Python dependency resolution
- **cargo** - Rust crate resolution
- **maven** - Java artifact resolution

### Real-World Scenarios

- **Express.js** - ~200 dependencies
- **React** - ~300 dependencies  
- **Next.js** - ~500 dependencies
- **Django** - ~100 dependencies
- **Tokio** - ~150 dependencies

## Results

Results are stored in `benchmark-results/` and tracked over time in CI.
